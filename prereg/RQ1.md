# prereg/RQ1 — 조건의 층위 분리와 모델별 관계의 통합 재정리·기계 검사 (AI 초안 v0.1)

- 작성일: 2026-11-01 (KST) · 작성: Claude(AI 조수) · 사람의 검토 전 · **동결 아님**
- 근거: 문서 02 §5.3, 문서 05 §4(G4 판정과 §4.5 결정), 모델 명세(`docs/spec/model-spec.md` v0.1, G2 잠정), 문서 04 §4(a)의 'G4 대조', `oracle/`, `formal/rq1/`, `prereg/README.md`
- 이 RQ는 통계 실험이 아니다. 사전 등록하는 것은 비교 대상, 분류 규칙, 기계 검사의 범위와 절차, 반례를 다루는 방법이다. 공통 통계 규약(SP-1–SP-4)은 적용하지 않고 SP-5(구현 무결성), SP-6, SP-7, SP-8만 적용한다.
- 이미 실행한 것: 소규모 전수 검사 10개 범위(프로세스 3–4개, 자원 종류 2–3개, 용량 1–3, 상태 595,676개)에서 정리 진술 위반 0건(`formal/rq1/sm-check-results.md`)과 변이 검사 7개 모두 검출(`formal/rq1/sm-mutation-results.md`). 이 두 결과는 이 계획이 쓰이기 전에 나왔으므로 사전 등록된 검사가 아니라 탐색 단계의 결과로 취급한다.

## 1. 질문

문헌에 나뉘어 있는 결과(대기 그래프 수준의 필요·충분·동치, 다중 단위의 반례, 정책 수준 결과, 예방 기법별 정리)를 하나의 정의 체계에서 같은 기호로 다시 쓰고 소규모 범위에서 기계로 검사하면, 어디서 정의 차이로 서술이 어긋나고 어디가 비어 있는가?

하위 질문(문서 05 §4.1의 하위 주장 코드):

- Q1-1 (WP1.1) 문헌의 정의는 용어마다(교착, 안전, 대기 그래프, 자원 할당 그래프, 매듭, 순환 대기) 어떻게 다른가? 우선 세 가지: (i) AND-OR 모델의 매듭 서술(문헌 M14, M17, M63), (ii) 순환 대기의 필요성(문헌 M70과 교재), (iii) '안전'의 뜻(문헌 M65의 직렬화 가능성과 뱅커 모델의 모든 프로세스가 끝나는 순서).
- Q1-2 (1c1) 모델 명세의 T2, T3, T5는 문헌 M62, M63, M14, M17의 정리와, 정의 차이를 보정한 뒤 같은 방향인가?
- Q1-3 (1c2) 대기 그래프 수준의 결과와 자원·용량이 드러나는 수준의 결과는 어떤 조건에서 대응하는가? (반례 B4의 일반화)
- Q1-4 (1d) 상태 수준에서 조건 사이에 어떤 함의가 성립하는가, 어떤 한정(극소 교착 집합 등)이 필요한가? (T1과 정책 수준 조건의 관계)
- Q1-5 (1e) 예방 기법(순서화, 일괄 요청, 타임스탬프, 천장 등)은 어떤 정책 수준 속성을 어떤 모델에서 제거·제한하는가? 어디서 건전하고 어디서 불충분한가?
- Q1-6 (1f) 위 진술들을 소규모 범위에서 독립 도구로 교차 검사하면 같은 결과가 나오는가? (선택: 핵심 정리의 기계 증명)

## 2. 주장하지 않는 것

- 새 틀을 만든다는 서술. 1a(정책·상태 수준의 구분)와 1c1(대기 그래프 수준의 필요·충분·동치)은 G4에서 '동일'로 판정했다(문서 05 §4.4). 대기 그래프 수준의 정리는 '재현'으로 쓴다.
- SM의 정의가 문헌의 교착과 같다는 서술. 오라클, 정리 진술, 검증이 모두 같은 정의에서 나왔으므로 정의 내부의 일관성만 보인다(`oracle/README.md`). 문헌과의 일치는 Q1-1과 Q1-2의 대조가 판정한다.
- 소규모 전수 검사의 통과를 정리의 증명이라고 쓰는 것, 검사하지 않은 범위(프로세스 5개 이상, 자원 종류 4개 이상, 용량 4 이상)에 대해 말하는 것.
- 1c2와 1e에 선행 서술이 없다는 서술. 이 칸들은 '이번 검색에서 찾지 못했다'이고, F1, F2, F10과 M64의 본문을 읽기 전에는 '없다'로 쓰지 않는다. 이 칸에 선행 기계 검증이 없다는 서술은 AFP와 Coq 색인을 직접 검색한 뒤에만 쓴다(문서 05 §4.5의 5항).
- M63의 정의와 SM의 정의 사이의 다섯 가지 차이(문서 04 §4(a))를 사실로 쓰는 것. 해석이며 M63 본문 확인 전이다.

## 3. 검토할 명제와 반증 조건

| 명제 | 반증하는 관측 |
|---|---|
| P1-a 모델 명세의 정리 진술(L1–L3, T1, T2, T2n, T3, T5–T8) 각각이 검사 범위의 모든 상태에서 성립한다 | 한 범위에서 위반 상태가 하나라도 나오면 그 진술은 반증됐다. 진술을 고치거나 적용 범위를 한정하고 변경 기록을 남긴다 |
| P1-b 문헌의 진술을 SM의 정의로 옮긴 진술이 같은 방향의 정리이다(재현) | 옮긴 진술이 범위 안에서 반례를 가진다. 이것은 문헌이 틀렸다는 뜻이 아니다(§6의 X) |
| P1-c 1c2의 대응 조건 후보 C가 '대기 그래프 순환 ⇒ 교착'을 보장한다 | 범위 안의 반례. 반례의 최소 크기를 기록한다 |
| P1-d 예방 기법 정리(T6, T7, T8)의 불변식 가정 아래 교착 집합이 없다 | 불변식을 만족하는 상태에서 교착 집합이 있으면 반증 |
| P1-e 독립 도구(Alloy 6, TLC)의 판정이 같은 입력에서 오라클과 일치한다 | 한 입력이라도 다르면 불일치. 어느 쪽 정의나 구현이 틀렸는지 찾을 때까지 결과를 보류한다 |

P1-c는 가설이다. 어떤 조건이 성립할지 이 계획에서 미리 말하지 않는다.

## 4. 비교 대상과 입력

**문헌.** 대기 그래프 수준: 문헌 M62(Herman–Chandy), M63(Barbosa), M14(Knapp), M17(Srinivasan–Rajaram). 자원·시스템 수준: M64(Chen–Rem), M1·M2(Kameda), M77. 정책 수준: M65(Yannakakis 외), 교재·강의 자료(T1, T2, T4, T6, T9, T10). 순환 대기의 필요성: M70. 원 출처: F1(Coffman 외 1971), F2(Holt 1972), F10(Levine). 우선 순위는 WP1.1의 세 가지 불일치 후보다.

**읽은 범위의 규칙.** 문헌 진술은 읽은 수준(A 원문, A− 도구 요약, B 초록, C 이하)과 쪽·절을 붙여 비교표에 올린다. A 또는 A−이 아닌 진술은 비교표에 올리되 '정의 차이'나 '어긋남'의 근거로 쓰지 않는다(수준 C 이하는 논증의 전제가 아니다). 원문이 없는 칸(F1, F2, F3, M64의 정리 번호, M65의 정리 번호)은 '원문 미확인'으로 표시하고 결론에서 뺀다(문서 02 §8).

**SM 정의.** 모델 명세 v0.1(G2 잠정)을 그대로 쓴다. 결정 항목 D1–D6이 바뀌면(특히 D1 교착의 기본 정의, D2 자기 대기의 포함) 이 계획의 모든 분류와 검사를 다시 실행하고 변경 기록에 영향을 적는다.

## 5. 검사 범위와 절차

**5.1 확대 범위(사전 등록).** 아직 검사하지 않은 범위를 아래처럼 추가한다. 상태 수가 2,000,000 이하이면 전수로, 넘으면 기록한 시드로 균일 표본 1,000,000개를 뽑는다(계획용 값). 표본 검사는 반례를 찾는 용도이며 범위에 대한 보장을 주지 않는다고 결과에 적는다.

| 범위 | 요청 형태 | 확대하는 축 |
|---|---|---|
| X1 | AND, OR | 프로세스 5개, 자원 종류 2개, 용량 1–2 |
| X2 | AND, OR | 프로세스 3개, 자원 종류 4개, 용량 1 |
| X3 | AND, 단일 단위 요청 | 프로세스 3개, 자원 종류 2개, 용량 4 |
| X4 | 일반 DNF(대안 3개까지) | 프로세스 3개, 자원 종류 2개, 용량 1–2 |
| X5 | 다중 단위 AND(벡터) | 프로세스 4개, 자원 종류 2개, 용량 (2,2)–(3,2) (B4 계열의 탐색) |

**5.2 독립 교차 검증.** 같은 정의를 Alloy 6(유한 트레이스 종료 교착은 stuttering으로 명시, P6)과 TLC로 다시 쓰고 소규모 범위에서 오라클과 판정을 비교한다(SI-2의 완료 기준, 문서 02 §4). 교착은 별도 상태 술어로 정의하고 그 도달 가능성을 검사한다(P6의 주의). 불일치는 P1-e대로 보류한다. 새 검사기마다 변이 검사를 한다(SP-5). 두 도구의 선택은 같은 입력에서의 성능으로 정한다(문서 02 §5.3). 이 검사는 정의 내부의 일관성만 보이므로 결과 서술에 그렇게 적는다.

**5.3 반례 탐색 규약.** (a) 범위 안은 전수 또는 §5.1의 표본. (b) 구성적 탐색: B1–B4의 계열을 체계적으로 일반화해 본다. (c) 1c2의 대응 조건 후보 C는 하나씩 적는다. 각 C에 대해 범위 안 반례 탐색을 하고 **시도한 C 전부(살아남지 못한 것 포함)와 최소 반례(프로세스 수 + 자원 용량 합이 최소)를 `formal/rq1/counterexamples.md`에 기록한다.** 살아남은 C는 '정리 후보'일 뿐이다(§6의 N).

**5.4 문헌 정의의 코드화.** 문헌의 정의가 SM과 다르다고 판정한 항목은 문헌의 정의를 따로 코드화해(`oracle/lit_*.py`) 그 정의 아래에서 문헌의 진술을 검사한다. 정의를 원문에서 확인하지 못한 항목은 '우리의 읽기'로 표시하고 어긋남의 근거로 쓰지 않는다.

**5.5 기계 증명(선택, CP4).** §6의 결정에 따른다. 후보 정리는 T2, T3, T5(a), T6–T8 가운데 기술이 안정된 것이며 도구는 Lean 4 + Mathlib, Isabelle/HOL, Rocq 가운데 사람이 고른다(문서 02 §10 Q5). 선행 기계 검증의 부재를 쓰려면 먼저 AFP와 Coq 색인을 검색한다.

## 6. 분류와 판정 규칙

진술마다 하나를 붙이고 근거(대장 ID, 쪽, 검사 범위)를 적는다.

| 분류 | 조건 |
|---|---|
| R 재현 | 문헌 진술을 SM의 정의로 옮긴 진술이 있고, 같은 방향이며, 범위 안 위반 0 |
| D 정의 차이 | 문헌이 쓰는 개념(정점 집합, 매듭의 기준 그래프, 자유 단위의 취급, 다중 단위의 표현 등)이 SM과 달라 옮김이 일대일이 아님. 차이를 목록으로 적고 가능하면 §5.4로 문헌 정의 아래에서 검사 |
| X 어긋남 | 옮긴(또는 문헌 정의로 코드화한) 진술이 범위 안 반례를 가짐. 문헌이 틀렸다고 단정하지 않는다: (i) 옮김을 재검토, (ii) 원문 확인, (iii) 저자의 가정 확인 뒤에만 '문헌 진술의 적용 범위 한정'으로 적는다 |
| G 빈칸 후보 | 이번 문헌 범위에서 해당 칸의 진술을 찾지 못함. 부재 증명이 아님 |
| N 정리 후보 | G 칸에 대해 SM에서 진술을 세웠고 범위 안 위반 0이며 증명 스케치가 있음. 증명(수작업은 사람 검토, 또는 기계 증명)과 원문 확인 전에는 정리라고 쓰지 않는다 |

**집계.** 하위 주장 1a–1f마다 진술 수를 R, D, X, G, N 별로 센다. 분류는 AI가 제안하고 사람이 확인한다. 분류를 바꿀 때는 사유를 적는다.

**중단·축소 규칙(문서 02 §5.3).** WP1.3 도중 같은 정리가 문헌에서 발견되면 그 정리는 R로 재분류한다. 1c2와 1e의 칸이 문헌에서 발견되어 모두 R이 되면 RQ1은 문헌 결과의 통합 재정리와 기계 검사 표로 축소한다(결과로 보고하고 종료). 소규모 전수 검사에서 반례가 나오면 진술을 수정하거나 범위를 한정한다.

**CP4(기계 증명 진행 여부)의 기준.** 모두 만족할 때만 진행한다: (i) WP1.4가 계획(3주)의 1.5배 안에 끝났다, (ii) 사람이 도구를 정했고 쓸 수 있다, (iii) 안정된 진술이 3개 이상이다(최근 변경 기록에서 두 번의 갱신 동안 바뀌지 않음), (iv) 대상 칸이 문헌 본문 확인 뒤에도 비어 있다. 하나라도 아니면 기록하고 건너뛴다.

## 7. 허용되는 사후 변경

허용(기록하고 이미 본 결과가 있는지 표시): 검사 범위의 추가, 비교표에 문헌 진술 추가, 분류 행 추가, 옮김의 오류 수정(수정 전 옮김과 사유를 남김), 모델 명세의 변경(명세 변경 기록과 영향 분석을 거쳐 전체 재실행).

허용하지 않음: 반례나 불일치가 나온 진술을 표에서 빼는 것, 옮김을 바꿔 X를 R로 올리면서 이유를 적지 않는 것, 증명 스케치만 있는 진술을 정리로 쓰는 것, 결과를 본 뒤 §5.1의 전수·표본 기준을 바꿔 결론을 바꾸는 것.

## 9. 한계

- 모델 명세는 G2 잠정이고 문헌 정의와의 대조가 끝나지 않았다. 원문(F1, F2, F10, M64, M65)을 읽지 못한 칸이 많다.
- 정리 진술의 증명은 AI가 쓴 스케치이며 사람 검토와 기계 검사 전이다.
- 검사 범위가 작다. 소규모 전수는 반례를 찾는 데 효과적이지만 모든 크기에 대한 보장은 수학적 증명이나 기계 증명이 필요하다.
- 알려진 구성(B1–B4)에서 출발한 탐색은 같은 구성의 변형에 치우칠 수 있다.
- RQ1의 초기 검색 약 35회는 기록이 남지 않아 문서 05의 RQ1 판정은 다시 열람해 확인한 것만 근거로 쓴다. 정방향 인용 추적은 하지 못했다(문서 05 §4.6, §8.5).
- 문헌과의 일치 판정에 쓰는 근거 대부분이 도구 요약(A−)이나 초록(B)이다.
