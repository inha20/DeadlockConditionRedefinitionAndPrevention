# experiments/ — 원자료와 실행 스크립트 보관 (SP-6)

이 폴더는 측정 실행의 원자료(JSONL), 시드, 실행 설정을 보관하는 자리다. **지금은 자료가 없다.** 본 실험은 사전 분석 계획 동결(`prereg-RQx-v1` 태그) 뒤에 돌린다.

- `pilot/` (파일럿 자료): 만들면 여기에 둔다. 파일럿 자료는 본 분석에 쓰지 않는다. 쓸 때에는 해당 `prereg/RQx.md`에 사전에 적는다(`prereg/README.md` §2).
- 실행 한 번마다 JSONL 하나와 그 실행의 머리 기록(마스터 시드, 셀 설정, 정책 목록, 환경 정보, git 커밋)이 함께 남는다(`bench/runner.py`).
- 제3자 자료는 두지 않고 링크와 해시만 둔다.
