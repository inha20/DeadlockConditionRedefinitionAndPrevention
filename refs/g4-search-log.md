# G4 검색 기록 (Phase 4)

- 문서 05(`docs/05-phase4-gate-decisions.md`)의 판정이 근거로 삼는 검색·열람 호출의 목록이다. 날짜는 2026-10-31–2026-11-01(KST)이다. G4-305는 G4 판정 뒤인 2026-11-02에 RQ2 격자 v0.2를 위해 더했다. G4-306–G4-372는 2026-11-07에 AV-3(M9의 정방향 인용 추적, 문서 07 §5)으로 더했고 RQ2 격자 v0.3의 근거다. 이 가운데 G4-362–G4-372는 사용자가 한 건에 한해 허락한(2026-11-07 21:31 KST) Eggermont 학위논문 열람이다. RQ1 행(G4-081 이후), RQ3 행(G4-131 이후), RQ5 행(G4-200 이후), RQ6 행(G4-251 이후)은 2026-11-01이다.
- 경로 분류: 키워드(K), 인용 추적(C), 인접 분야(A), 직접 열람(R, 후보의 본문·문서를 읽은 호출).
- 열람 도구는 본문을 요약해 돌려주므로 R 호출로 얻은 수치와 문장은 A−다. 도구가 읽지 못한 것(이진 데이터, 오류)도 적는다.
- 이 표의 '결과'는 이번 호출에서 본 것만 적었다. 못 찾았다는 것은 부재 증명이 아니다.
- 환경 한계: 작업공간 셸은 외부 학술 API에 닿지 않는다(프록시가 api.openalex.org를 거부했다). OpenAlex의 단건 조회(`works/doi:…`)는 열람 도구로 되지만 목록 질의(`filter=`, `search=`)는 5회 모두 client_error였다. Semantic Scholar의 단건·인용 조회는 되고 검색 질의는 client_error였다. Crossref는 `query.bibliographic`이 되고 `filter=`가 붙은 질의는 client_error였다. DBLP는 robots_disallowed였다. 거부된 경로를 우회하지 않았다. 2026-11-07 추가: OpenCitations Index API v2(`api.opencitations.net/index/v2/citations/doi:…`)는 열람 도구로 되며(첫 주소는 같은 기관의 다른 주소로 리다이렉트되어 따라가야 했다), Meta API는 URL 길이 제한 때문에 한 번에 DOI 4개까지만 물을 수 있었다(8개 이상은 HTTP 403). 열람 도구는 doi.org 링크 두 건(IEEE)과 Springer 장 한 건을 SITE_BLOCKED로 막았고 우회하지 않았다. 이 차단은 CAPTCHA 화면이 아니라 사이트 단위 차단이었다. 사용자가 CAPTCHA를 직접 풀겠다고 해(2026-11-07 21:16 KST) 같은 페이지를 내장 브라우저 창으로 열었고(G4-348 이후 '내장 브라우저' 행) CAPTCHA는 한 번도 나타나지 않았다. IEEE Xplore와 Springer의 본문은 로그인이나 구독이 필요해 초록과 목차까지만 읽었다. 파일은 내려받지 않았다.
