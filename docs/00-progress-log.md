## 작업 방식

- 정본은 Claude의 작업공간에 있는 저장소 사본이고, 사용자 PC의 이 폴더는 그 사본을 복사해 둔 것이다. 작업공간에서 만든 파일을 PC로 복사할 때 PC 쪽 파일이 그사이 바뀌었는지 확인한다.
- git 이력은 작업공간의 저장소에만 있다. 이 폴더는 아직 git 저장소가 아니다(저장소 생성 전, 아래 "막힌 것").
- 코드와 실험은 작업공간(코어 2개, 메모리 약 8GB)에서 돌린다. 커널 실험과 유료 원문 열람은 사용자 쪽 작업이 필요하다.
- 근거 수준 표기와 게이트 규칙은 문서 01, 02를 따른다. 확인하지 못한 것은 X로 둔다. 자체 계산 결과는 수준 V로 구분한다(`refs/claims-ledger.md` 머리말).

### Phase 2에서 한 것

- `docs/spec/model-spec.md` v0.1: 스냅샷 모델 SM의 정의(상태, 요청 형태의 DNF 표현, 가정 A1~A4와 W1), 교착 집합의 정의, 자기 대기와 FD, 상태 수준 술어, 코프만 조건의 정책 수준·상태 수준 분리, 정리 진술 11개와 증명 스케치, 모델 매트릭스 초안(10행)과 반례 4개, 정책 분류(잠정), 결정 항목 D1~D6.
- `oracle/sm.py`: 정의를 그대로 옮긴 참조 구현. `oracle/check_sm.py`: 정리 진술을 10개 소규모 범위의 595,676개 상태에서 전수 검사. 위반 0건. 결과는 `formal/rq1/sm-check-results.md`.
- 순열 전수 탐색(L3)은 축소 구현과 독립이며 전 범위에서 일치했다.
- `oracle/mutation_check.py`: sm.py에 일부러 넣은 오류 7개를 검사 모음이 모두 검출했다(`formal/rq1/sm-mutation-results.md`). 0건 통과가 검사가 비어 있어서가 아님을 보이는 용도다.
- 도구 설치 가능성(항목 6): Alloy 6.2.0과 TLC가 작업공간에서 실행됨을 확인했다(문서 02 §1.3).
- 문서 01 §1.2의 문헌 서술 중 두 가지가 SM 결과와 맞춰 보면 적용 범위를 좁혀 읽어야 한다는 단서를 얻었다. 문서 01은 아직 고치지 않았다.
  - 59행(AND에서 대기 그래프 순환이 필요충분)은 다중 단위에서는 성립하지 않는 반례가 있다(명세 §7 B4, 주장 C-RQ1-003).
  - 60행은 OR와 일반화 모델을 한 줄로 묶었다. M17 §1(A−, 도구 요약 경유)은 둘을 다르게 서술한다(주장 C-RQ1-004). 본문 대조 뒤에 행을 나눌지 정한다.

- 판정: **G3 조건부 통과**. 비용표의 수치 칸 상당수가 X이고(같은 조건 비교 문헌 없음, RQ3 측정이 채울 칸), 유료 원문 미확인 칸이 있으며, RQ6 재현 대상의 최소 건수는 사람이 정해야 한다.

- 보고서 수치를 이번 세션의 열람 기록과 대조해 고친 것: 열람 횟수(88회), "분리 5건"을 4건+탐지 1건으로, Knapp §2.2를 단일 단위 한정으로 읽은 표현(Knapp는 한정을 명시하지 않음, 단일 단위 한정은 SM의 T2), "서로 반박" 문장, 저자 확인이 안 된 M38의 표기, 'two orders of magnitude' 번역.
- 새로 알게 된 것(요약): 기준 복잡도 표기 불일치의 출처 후보(Li 2013이 O(n³d)로 쓰고 Θ(n²d)류는 안전성 검사 부분의 오인용이라고 설명), 같은 안전성 문제가 모델 변수에 따라 다항에서 NP-완전·결정 불가능으로 갈리는 경계, 이중 락 비중이 표본에 따라 22.6%~78.9%(분모가 달라 비교 불가), 확인한 락 API의 자기 대기 계약이 서로 다름(POSIX 유형별, Linux 금지, Rust 미규정).

### 막힌 것

- **저장소 이름**: 아직 정해지지 않았다(사용자가 "조금 더 있다가 정하자"고 했다). 후보는 `deadlock-conditions-research`, `os-deadlock-prevention-research`, `redefining-deadlock-conditions`. 이름을 정해 주기 전에는 저장소를 만들지 않고 GitHub 로그인도 요청하지 않는다.
- **저장소 생성 권한**: 작업공간의 `gh` 토큰이 유효하지 않다. 경로는 (1) 사용자가 GitHub에 빈 공개 저장소를 만들거나 브라우저에서 로그인해 두면 (2) 작업공간에 그 저장소를 연결하고 (3) 커밋 이력을 푸시하는 것이다.
- **유료 원문**: F1(Coffman 외 1971), F2(Holt 1972), F3(Habermann 1969)과 이에 연결된 M3, M4, M5, M18, M19. 사람이 PDF를 주면 WP1.1과 모델 매트릭스를 원문 위치로 채운다(문서 03 §9).
- **Linux 실행 환경**: 커널 실험(L4, RQ5 일부)에 필요하다. 미정.
