## 0. 읽는 법

- **진술**이라고 쓴다. 정리라고 쓰려면 증명 스케치의 사람 검토 또는 기계 증명과 원문 확인이 필요하다(`prereg/RQ1.md` §6의 N).
- 검사 열의 '범위 수 / 적용 상태 수 / 위반'은 `formal/rq1/sm-check-results.md`에서 가져왔다. '적용 상태 수'는 진술의 전제를 만족해 실제로 검사한 상태 수다(전제가 없는 상태는 건너뜀). **검사 통과는 증명이 아니다**: 범위가 작고(프로세스 3–4개, 자원 종류 2–3개, 용량 1–3) 정의·구현·진술이 같은 정의에서 나왔다.
- 이 검사는 `prereg/RQ1.md`가 쓰이기 전에 나왔으므로 **사전 등록된 검사가 아니라 탐색 단계의 결과**다(prereg 서두).
- 증명 스케치는 명세 §6.1에 있다. AI가 쓴 것이며 사람 검토 전이다.
- 문헌 짝의 수준(A, A−, B, C, D)은 문서 01 §0.1을 따른다. 문헌 서술은 대부분 도구 요약이며 원문 재확인 전이다.

## 4. 문헌 짝과 분류의 근거 요약

- **1c1 (대기 그래프 수준) 동일.** T2, T3, T5와 짝이 되는 AND→순환, OR→매듭, AND-OR→b-매듭(M63 Thm 1.3–1.5), '모든 모델에서 순환이 필요'(M63), M17 §1(AND-OR·P-out-of-Q에서 순환 필요·불충분, 매듭 충분·불필요)이 있어 방향이 같다(문서 05 §4.4). 서술이 어긋나 보이는 곳(M14 §2.4, M17 §1, M63)은 매듭의 뜻이 달라서일 수 있다. 정의 비교표 §3(i)이 이를 정리한다.
- **1a, 1d (조건 사이의 함의, 정책 수준 대 상태 수준).** 교재 수준(C)의 서술은 있으나 원 출처 F1, F2의 본문을 읽지 못했다. T1(a)과 T1(d)은 '교착이면 점유 대기와 순환 대기가 성립한다'는 교재 서술의 상태 수준 한정 형태다. 한정(극소 집합, FD)이 교재 서술과 같은 층위인지는 확인하지 못했다.
- **1c2 (자원·용량 수준).** 대기 그래프 수준 결과가 자원·용량이 드러나는 스냅샷에 어떤 조건에서 옮겨지는지를 반례(B4)와 함께 한 번에 정리한 문헌을 이번 범위에서 찾지 못했다. 이것은 '없음'이 아니며 F2, M64의 본문을 읽기 전에는 '없다'로 쓰지 않는다. 지금 이 표에는 1c2의 대응 조건 C를 적은 진술이 **없다**(아래 §5).
- **1e (예방 기법).** T6, T7은 Havender(F6)의 기법을 상태 불변식으로 옮긴 진술이다. 기법별·모델별 건전성의 분류(불충분한 모델의 반례 포함)는 이번 범위에서 찾지 못했다. T8의 정리 수준 근거는 원 출처 미확인이다.
- **1f (기계 검사).** 자원 할당 이론을 증명 보조기나 소규모 전수 검사로 검증한 선행은 이번 범위에서 찾지 못했다(C-SUR-138). 이 표의 검사는 같은 정의 안의 일관성만 보인다. AFP와 Coq 색인을 직접 검색하기 전에는 '선행 없음'을 쓰지 않는다.

## 6. 한계

- SM 정의는 G2 잠정이며 D1(교착 집합 정의)과 D2(자기 대기, FD)에 의존한다. T1(c), T1(d), T8은 FD에 의존하므로 D2가 바뀌면 영향받는다. D1 또는 D2가 바뀌면 모든 분류와 검사를 다시 실행한다(`prereg/RQ1.md` §4).
- 검사 범위가 작다(프로세스 2–3개). 프로세스 4개 이상, 자원 종류 4개 이상, 용량 4 이상, 대안 3개 이상은 검사하지 않았다.
- 증명은 AI의 스케치이며 사람 검토 전이다.
- 문헌 짝의 근거가 대부분 도구 요약(A−)이나 초록(B)이다. F1, F2, F10과 M64, M65의 정리 번호를 읽지 못했다(열린 항목 O1-1). 정방향 인용 추적을 하지 못했다.
- 이 표의 분류는 AI의 제안이다. 분류를 바꿀 때는 사유를 적는다(`prereg/RQ1.md` §6).
