- 하지 않는 일: 문헌이 틀렸다는 판정, 'X 어긋남' 분류, 문헌 정의의 코드화(`oracle/lit_*.py`. 원문의 정의 문구가 없어 지금은 못 한다), 기계 검사.

## 0. 읽는 법

- 수준은 문서 01 §0.1을 따른다. A는 원문, A−는 열람 도구가 돌려준 본문 요약, B는 초록이나 목록 항목, C는 2차 서술(교재 사본, 강의자료), D는 서지나 귀속 서술이다.
- `prereg/RQ1.md` §4의 규칙에 따라 **A 또는 A−가 아닌 진술은 표에 올리되 '정의 차이'의 근거로 쓰지 않는다**(표에서 '근거 아님'으로 표시). 정리 번호와 정의의 문구는 원문으로 재확인하기 전에는 논증의 전제로 쓰지 않는다.
- '요약에 없음'은 열람한 요약에 서술이 없다는 뜻이지 '원문에 없다'가 아니다.
- 'SM'은 이 저장소의 스냅샷 모델(`docs/spec/model-spec.md` v0.1, G2 잠정)이다. SM의 정의는 결정 D1–D6에 의존한다(§5).

| T1(Silberschatz 사본) | 순환 대기가 점유 대기를 함의해 네 조건이 완전히 독립은 아니다 | 정책·상태 혼재 | C | 근거 아님 |
| T-series | 필요/충분 표기가 교재마다 일관되지 않음(T5, T7, T10) | — | C | 근거 아님 |

## 3. 우선 불일치 후보 세 가지 (Q1-1)

### (i) AND-OR 모델의 매듭 서술 (M14, M17, M63)

| 출처 | 서술 | 수준 |
|---|---|---|
| M14 §2.4 | AND-OR에는 표준 그래프 구조가 없다. OR 검사를 반복하면 되나 비효율 | A− |
| M17 §1 | AND-OR, P-out-of-Q에서 순환은 필요하나 충분하지 않고 매듭은 충분하나 필요하지 않다 | A− |
| M63 Thm 1.5 | AND-OR은 b-매듭일 때 교착 (필요충분) | A− |
| SM T5 | 일반 DNF에서 expedient이고 RAG 매듭이 있으면 교착(충분). 역은 성립하지 않는다(필요 아님) | 검사 범위 안 |

**읽기(해석).** M17의 '매듭'이 단순 매듭이고 M63의 'b-매듭'이 일반화된 개념이라면 둘은 모순이 아니다. M14 §2.4의 '표준 그래프 구조 없음'은 '단순 매듭 특성화가 없다'는 뜻일 수 있다. 어느 읽기가 맞는지는 세 원문의 정의를 대조해야 안다. 분류 제안: **D 후보**(정의 차이일 가능성이 큼). 원문 확인 전에는 결론이 아니다.

### (ii) 순환 대기의 필요성 (M70과 교재)

| 출처 | 서술 | 수준 |
|---|---|---|
| M70 | 자원 순환 대기가 교착 없이 일어나는 반례를 들어 고전의 서술이 과도한 단순화라 논한다 | B |
| 교재 | 순환 대기를 교착의 필요조건으로 서술하는 곳이 있고 필요/충분 표기가 일관되지 않다 | B, C |
| SM T2n | 교착이면 WFG와 RAG 모두에 순환이 있다(자기 간선 허용). 필요조건이다 | 검사 범위 안 |
| SM T5(d), B2–B4 | RAG에 순환이 있어도 교착이 아닐 수 있다(충분조건이 아님) | 검사 범위 안 |

**읽기(해석).** 자원 순환 대기가 교착 없이 일어나는 반례는 순환이 **충분조건이 아님**을 보이는 것이다(SM의 B2–B4가 같은 종류). 필요성의 반박이 아니다. M70이 필요성을 반박하는지는 초록이 모호하다(문서 05 §4.4). 본문 확인 전에는 결론짓지 않는다. 또 M70의 '자원 순환 대기', '사건 순환 대기'가 SM의 순환 대기(D(U) 강연결, WFG·RAG 순환)와 같은 정의인지도 대조해야 한다. 근거 수준 B이므로 분류하지 않는다.

### (iii) '안전'의 뜻 (M65와 뱅커 모델)

§2.2와 같다. 분류 제안: **D 정의 차이**. 용어의 뜻이 다르며(M65: 직렬화 가능한 스케줄만 허용, 뱅커형: 완료 순서가 존재) 어느 쪽 진술도 반증되지 않는다.

## 4. M63과 SM 사이의 다섯 가지 차이 (해석, M63 본문 확인 전)

문서 04 §4(a)의 'G4 대조'를 그대로 옮긴다. 모두 **해석**이며 사실로 쓰지 않는다(`prereg/RQ1.md` §2).

| 번호 | 차이 | 남은 것 |
|---|---|---|
| 1 | 객체의 위치: SM의 WFG·RAG는 (cap, alloc, alts)에서 파생되는 술어용 보조 객체이고 교착은 sat와 cap − A(U)로 따로 정의된다. M63의 대기 그래프는 프로세스 정점만 갖는 모델 자체이며 요청 형태는 나가는 간선 묶음의 제약이다 | M63 §3의 정의로 재확인 |
| 2 | 매듭의 기준: SM은 RAG 기준, M63은 대기 그래프 기준. expedient 상태에서 두 정의가 같은 집합을 가리키는지 확인하지 않음 | WP1.1에서 확인 |
| 3 | 자유 단위: SM의 WFG는 자유 단위가 있어도 간선을 만든다(과대 근사). M63의 대응 처리를 확인하지 못함 | 본문 |
| 4 | 다중 단위: M63이 다중 단위 자원을 대기 그래프에서 어떻게 표현하는지 확인하지 못함. SM의 B4는 한 종류의 단일 단위 요청이 그 단위를 쥔 프로세스들에 대한 OR 의존이 되는 사례로 읽을 수 있음. 맞으면 B4는 AND 대기 그래프 정리의 반례가 아니라 '자원 요청의 AND'와 '의존의 AND'가 다름을 보이는 사례 | 다중 단위에서 순환이 교착을 뜻하지 않는 예가 문헌에 있는지는 F2 본문 확인 전 |
| 5 | 매듭의 일반화: M63의 b-매듭은 SM T5의 단순 RAG 매듭보다 일반화된 개념으로 보임. 그렇다면 SM T5(b)의 '역은 성립하지 않는다'와 M63 Thm 1.5의 '필요충분'은 매듭의 뜻이 달라 모순이 아닐 수 있음 | M14 §2.4, M17 §1과의 어긋남도 같은 종류일 수 있음 |
