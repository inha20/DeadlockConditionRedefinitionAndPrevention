## 반례가 있을 것으로 예상한 진술(예시)

각 진술이 일반적으로는 성립하지 않음을 보이는 가장 먼저 발견된 상태다. FD는 자기 대기(이미 쥔 양을 더하면 용량을 넘는 대안)가 없다는 조건이다.

- 교착이지만 매듭 없음(매듭은 필요조건이 아님) — FD 만족(자기 대기 없음), AND·용량1·m=3·n=3 범위: `용량[1, 1, 1] Free[1, 0, 0] | P0: 보유[0, 0, 0] 요청-; P1: 보유[0, 0, 1] 요청[[0, 1, 0]]; P2: 보유[0, 1, 0] 요청[[1, 0, 1]]`
- 교착이지만 매듭 없음(매듭은 필요조건이 아님) — FD 위반(자기 대기 포함), AND·용량1·m=3·n=3 범위: `용량[1, 1, 1] Free[1, 1, 0] | P0: 보유[0, 0, 0] 요청-; P1: 보유[0, 0, 0] 요청-; P2: 보유[0, 0, 1] 요청[[1, 0, 1]]`
- RAG에 순환이 있으나 교착 아님(순환은 충분조건이 아님) — FD 만족(자기 대기 없음), OR·용량1·m=3·n=3 범위: `용량[1, 1, 1] Free[1, 0, 0] | P0: 보유[0, 0, 0] 요청-; P1: 보유[0, 0, 1] 요청[[0, 1, 0]]; P2: 보유[0, 1, 0] 요청[[0, 0, 1], [1, 0, 0]]`
- RAG에 순환이 있으나 교착 아님(순환은 충분조건이 아님) — FD 위반(자기 대기 포함), OR·용량1·m=3·n=3 범위: `용량[1, 1, 1] Free[1, 1, 0] | P0: 보유[0, 0, 0] 요청-; P1: 보유[0, 0, 0] 요청-; P2: 보유[0, 0, 1] 요청[[0, 0, 1], [1, 0, 0]]`
- expedient이고 RAG에 순환이 있으나 교착 아님 — FD 만족(자기 대기 없음), OR·용량1·m=3·n=3 범위: `용량[1, 1, 1] Free[0, 0, 0] | P0: 보유[0, 0, 1] 요청-; P1: 보유[0, 1, 0] 요청[[1, 0, 0]]; P2: 보유[1, 0, 0] 요청[[0, 0, 1], [0, 1, 0]]`
- expedient이고 RAG에 순환이 있으나 교착 아님 — FD 위반(자기 대기 포함), OR·용량1·m=3·n=3 범위: `용량[1, 1, 1] Free[1, 0, 0] | P0: 보유[0, 0, 0] 요청-; P1: 보유[0, 0, 1] 요청-; P2: 보유[0, 1, 0] 요청[[0, 0, 1], [0, 1, 0]]`
- expedient이고 AND 요청이며 다중 단위 자원이 있을 때 대기 그래프에 길이 2 이상 순환이 있으나 교착 아님 — FD 만족(자기 대기 없음), OR·용량(2,2)·n=3 범위: `용량[2, 2] Free[0, 0] | P0: 보유[0, 1] 요청-; P1: 보유[0, 1] 요청[[1, 0]]; P2: 보유[2, 0] 요청[[0, 1]]`

검사 이름(문서 spec/model-spec.md §6의 진술과 같은 이름):

- L1: 교착 집합의 합집합은 교착 집합이다
- L2: 축소의 잔여 = 가장 큰 교착 집합
- L3: 순열 전수 탐색으로 전원이 끝날 수 있음 ⟺ 교착 집합이 없음
- T1a: 극소 교착 집합의 모든 구성원이 단위를 쥔다
- T1b: 극소 교착 집합의 의존 그래프가 강연결이다(크기 1이면 자기 간선)
- T1c: FD이면 크기 1인 교착 집합이 없다
- T1d: FD이면 극소 교착 집합의 의존 그래프에 길이 2 이상의 순환이 있다
- T2: 용량 1, AND: 교착 ⟺ 대기 그래프 순환(자기 간선 포함)
- T2n: 교착이면 대기 그래프에 순환이 있다
- T3: 단일 단위 대안: expedient 상태에서 교착 ⟺ 자원 할당 그래프의 매듭
- T3i: 단일 단위 대안: 교착이면 매듭이 있다(expedient 불필요)
- T5a: expedient이고 매듭이 있으면 교착이다
- T5c: 교착이면 자원 할당 그래프에 순환이 있다
- T6: 순서 불변식(ORD)이면 교착 집합이 없다
- T7: 대기 중 아무것도 쥐지 않으면(ALL) 교착 집합이 없다
- T8: FD이고 대기 간선이 모두 같은 방향이면(타임스탬프 불변식) 교착 집합이 없다
